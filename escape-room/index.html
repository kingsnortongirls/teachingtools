ROOM 03 / ALGORITHM ENGINETarget: 6 minutes

Trace the corrupted program

The system reports a security value generated by a short algorithm. It will not accept a guessed final number. Complete the trace table for each loop iteration.

Operator manual

MOD gives the remainder after division. So 4 MOD 2 = 0, whereas 3 MOD 2 = 1. Multiplication happens before addition and subtraction. A variable keeps its new value between iterations.

ROOM 04 / LOGIC POWER GRIDTarget: 4 minutes

Three switches, one solution

The backup power is controlled by three binary inputs. Change A, B and C until all three output lamps are ON (1), then submit the switch pattern.

Gate reference

AND = both inputs are 1. OR = at least one input is 1. NOT = reverse the input. XOR = the inputs must be different. Work from the conditions, not random guessing.

DOOR: 0A XOR BRequired: 1
ALARM: 0(A AND B) OR CRequired: 1
BACKUP: 0(NOT A) AND CRequired: 1
All three outputs must read 1 simultaneously. Your evidence will be the three input bits in A-B-C order.
ROOM 05 / PACKET RECOVERYTarget: 6 minutes

Recover the lost command

A message was split into four packets and sent out of order. Two packets are corrupt. Work out which are valid, then select the four valid packets in ascending sequence order.

Checksum rule

Find each letter's alphabet position (A=1 to Z=26), add the values, then keep only the final digit of the total. That digit must equal the checksum on the packet. Example: HI = 8 + 9 = 17, so checksum = 7.

Receiving buffer (tap a selected packet to remove it)

Two packets have incorrect checksums. You need exactly one packet for each sequence number.
ROOM 06 / FINAL OVERRIDETarget: 3 minutes

The master lock

The console requires all your recovered evidence. Consult the log and derive a new four-digit PIN. You must enter three values correctly to complete the mission.

Master PIN instructions

Make the four-digit PIN in this exact order: (1) number of ON inputs in the logic switch pattern; (2) number of letters in the binary password; (3) the last digit of the sum of the two digits in the algorithm's final value; (4) number of relay devices between CONSOLE and VAULT on the chosen route. Keep leading zeroes if any.
