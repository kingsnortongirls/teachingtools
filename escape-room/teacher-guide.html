Operation Blackout: Teacher Guide

Original six-stage, approximately 30-minute Computer Science escape room for Year 7 to Year 9.

Open student gameTeaching Tools homepage

Lesson at a glance

Format: pairs or groups of three, one browser per team, ideally with paper for calculations. The game itself runs for approximately 30 minutes. Brief before starting and debrief afterwards where lesson time permits.

StageSuggested timeSkills
1. Network Rescue6 minutesConstraints, routing, graphical problem solving
2. Binary Vault5 minutes8-bit binary, denary conversion, ASCII

4. Logic Power Grid4 minutesAND, OR, NOT, XOR and Boolean reasoning

Total challenge time: 30 minutes. The clock counts down, but students can continue after time expires. Local browser storage retains progress on that browser only.

Teacher preparation: Check students can open escape-room/ on the school network. No accounts, external packages or network requests are required. Students can access the answers by inspecting source code or guessing; this is a learning challenge, not a secure test.

Stage-by-stage answers and teaching notes

1. Network Rescue

Follow wired links only, avoid C2 (quarantined), E9 (offline) and the wireless CONSOLE–B7 link. The valid shortest path is CONSOLE → A4 → D5 → F1 → VAULT, four links. The relay tag is the digits of A4, D5 and F1.

Answer: route S → A → D → F → V; evidence tag 451.

Potential misconception: wireless links are still connections but are disallowed under the scenario's emergency rule. Discuss why a route can be connected yet unacceptable.

2. Binary Vault

Convert each byte using the place values 128, 64, 32, 16, 8, 4, 2 and 1.

BinaryDenary workingASCII
0100111064 + 8 + 4 + 2 = 78N
0100111164 + 8 + 4 + 2 + 1 = 79O
0100010064 + 4 = 68D
0100010164 + 4 + 1 = 69E

Answer: NODE.

Potential misconception: reading the bits as denary digits. Each binary 1 marks a place value to add.

3. Algorithm Engine

Starting value: 6. For odd tick numbers add three times the tick; for even tick numbers double the current value and subtract the tick.

TickWorkingCharge
16 + (1 × 3)9
2(9 × 2) − 216
316 + (3 × 3)25
4(25 × 2) − 446

Answer: [9, 16, 25, 46]. Evidence code: 46.

Students must supply every intermediate value, not simply the final answer. For errors, the game identifies the first incorrect row.

4. Logic Power Grid

BACKUP = (NOT A) AND C must be 1, forcing A = 0 and C = 1. DOOR = A XOR B must also be 1, forcing B = 1. ALARM = (A AND B) OR C then equals 1.

Answer: A = 0, B = 1, C = 1. Evidence pattern: 011.

Extension: ask students to build an eight-row truth table and prove the pattern is unique.

5. Packet Recovery

Checksum = the final digit of the sum of alphabet positions of the payload letters. Select four packets in ascending sequence order.

Seq / payloadCalculationResult
01 RE18 + 5 = 23; last digit 3Valid (3)
02 ST19 + 20 = 39; last digit 9Valid (9)
03 OR15 + 18 = 33; last digit 3Valid (3)
04 E5; last digit 5Valid (5)
02 STExpected 9, packet says 6Corrupt
03 ZX26 + 24 = 50; last digit 0, packet says 2Corrupt

Answer: SEQ 01 RE → SEQ 02 ST (checksum 9) → SEQ 03 OR (checksum 3) → SEQ 04 E. Evidence: RESTORE.

Discuss error detection versus correction. The toy checksum can detect some errors, not all possible corruptions.

6. Final Override

The packet command is RESTORE and the relay tag is 451. The new PIN is derived as follows: logic pattern 011 has 2 ON inputs; binary word NODE has 4 letters; algorithm result 46 gives 4 + 6 = 10, final digit 0; safe route has 3 relay devices.

Final command: RESTORE. Relay tag: 451. Master PIN: 2403.

Differentiation, accessibility and challenge

  • Year 7 / SEND: place students in mixed-attainment teams, provide a printed 128–1 place-value strip, a worked example of a trace table, and the basic logic-gate definitions. The two in-game hints provide graduated prompts without showing the answer.
  • Year 8: expect students to justify each network hop and demonstrate how they know which packets are corrupt.
  • Year 9 / greater depth: require a written explanation of why the logic solution is unique, why the route is shortest, and how to improve the checksum scheme.
  • Accessibility: all controls are keyboard-operable, feedback is text-based, the network map scrolls horizontally on narrow screens and high-contrast colours are used. The timer never blocks students when it reaches zero.
  • If a team finishes early: ask them to design a seventh room with a new algorithm or a parity-bit puzzle, giving both a worked solution and two graduated hints.

Assessment and facilitation

Circulate rather than reveal the solutions. Ask: “What restriction rules out that path?”, “Which branch executes at tick 3?”, “How did you check the checksum?” and “What previous result does the master lock need?”

Teams start at 600 points. A revealed hint costs 15 and a rejected submitted answer costs 5. Timer overtime does not cost points. Scores are motivational, not formal grades. The browser saves progress locally; restarting clears that browser's attempt. The printable completion certificate contains the entered team name only.

Suggested plenary: students each write one thing they knew, one technique they learnt and one decision they changed after testing. Emphasise reasoning rather than speed.
