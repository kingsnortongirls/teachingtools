Lossless and lossy

Lossless: decompression reconstructs every original value exactly. Lossy: some detail is discarded to reduce file size. Changing colour depth here demonstrates lost precision, not a real JPEG encoder.

File-size figures represent raw payload only. Real file formats may add headers, metadata, padding or compression.
