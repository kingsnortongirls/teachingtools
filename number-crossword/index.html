      Binary place-value reminder

      Read bit weights from right to left: 1, 2, 4, 8, 16, 32, 64, 128. Add the weights wherever a bit is 1.

      Example: 1011₂ = 8 + 2 + 1 = 11₁₀.

      Hexadecimal reminder

      One hex digit represents four bits. The extra symbols are A=10, B=11, C=12, D=13, E=14 and F=15.

      Example: 2F₁₆ = (2 × 16) + 15 = 47₁₀.
