How labels, branches and memory work

A label names a mailbox. The assembler converts labels to numbered addresses. STA TOTAL saves the accumulator value in the data mailbox labelled TOTAL, while LDA TOTAL retrieves it. BRA LOOP jumps to a labelled instruction, and BRZ or BRP jumps only if its condition is satisfied.

This classroom simulator supports signed integers for the negative-input examples in the worksheets, rather than enforcing only the unsigned 0–999 data range of some LMC implementations. Program instructions still use standard 000–999 machine codes. Arithmetic is bounded to −999 to 999 here, and the simulator stops on overflow rather than wrapping.
