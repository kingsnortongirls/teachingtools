Compare A with a. What changes? Try a symbol such as £ or an emoji. Why do some characters require more than one UTF-8 byte?

ASCII uses 7 bits for 128 characters. UTF-8 preserves ASCII byte values while allowing other Unicode characters to use multiple bytes.
