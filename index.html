What does unsigned mean?

An unsigned binary number represents zero and positive whole numbers. Signed numbers can also represent negative values, but use a different interpretation of the bits.

Experiment 07 · Storage

File size calculator

Convert between storage units and understand why a computer's reported size may be different from the value on a storage device's label.

Converted amount

Decimal units: 1 kB = 1,000 bytes; 1 MB = 1,000,000 bytes; 1 GB = 1,000,000,000 bytes.
Binary units: 1 KiB = 1,024 bytes; 1 MiB = 1,048,576 bytes. One byte always contains 8 bits.
Why is a 1 TB drive not always shown as 1,000 GB?

Some systems use binary units when reporting sizes, sometimes labelling them ambiguously. For example, one decimal terabyte is approximately 931 GiB. File system overhead can also reduce available space.
