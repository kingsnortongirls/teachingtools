Image Compression Lab

What happens to an image when we reduce its file size? Compare original images with real JPEG and PNG encodings, inspect the differences and explore the compromises.

3. Compare JPEG quality settings

Drag the slider towards lower quality. File size usually falls, but fine details and sharp boundaries can change. Zoom in to make artefacts easier to spot.

Lossless compression

Removes redundant data without changing the decoded image. It can be decompressed to reproduce the original pixels exactly.

Example: PNG uses lossless compression. Simple graphics, text and repeated colours often compress well.

Lossy compression

Discards some image information to reduce file size. The exact original pixels cannot usually be recovered from the compressed file.

Example: JPEG usually works well for photographs, but can introduce visible artefacts at lower quality settings.

4. Check your understanding

Example answers:

1. Lossless compression retains every pixel, so text and diagrams remain sharp and the decoded image is identical to the original.

2. Smaller files transfer faster and use less storage; however, lost image details and compression artefacts may reduce visual quality.

3. No. Once information has been discarded by lossy compression, increasing the later quality setting cannot recreate the missing original data.

GCSE J277: Key terms

Compression: reducing the number of bits required to store or transmit a file. Lossless: reconstructs exactly the original data. Lossy: permanently removes some data, often achieving a smaller file.

Investigate why photographs tend to suit JPEG, and why images with flat areas, symbols or text often suit PNG. This experiment compares image data only. The uploaded original file's own size is not a valid uncompressed baseline, because it may already be compressed.
